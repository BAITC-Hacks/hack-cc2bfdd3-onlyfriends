# OnlyFriends: прогноз мощности ВЭС

Воспроизводимый почасовой прогноз нормализованной активной мощности двух турбин на 48 часов. Для каждого исторического запуска используется отдельный архивный выпуск ECMWF IFS, доступность которого оценивается до момента расчёта. Числовой прогноз выполняет обученная модель; кодовый оркестратор запускает загрузку, проверки, расчёт, анализ и запись происхождения результата.

## Состояние

Реализованы загрузка истории, обучение с помесячной проверкой, архив погоды, прогноз одного выпуска и последовательный ретропрогноз. История организаторов **не публикуется** в Git; положите свои копии двух CSV в `raw/`. Февральских значений мощности в исходных файлах нет, поэтому февральский MAE/RMSE нельзя вычислить до получения факта. Демонстрационная визуализация из [видения проекта](docs/PROJECT_VISION.md) пока не входит в эту реализацию модели.

## Данные и временные правила

- `raw/*turbine 1.csv` и `raw/*turbine 2.csv`: исходные 10-минутные данные с колонками `Статистическое время`, `Средняя скорость ветра(m/s)`, `Нормализованная активная мощность`, `Средняя температура окружающей среды(°C)`.
- Часовая цель — средняя мощность из минимум четырёх корректных записей. Недостаточно покрытые часы не используются. 12 неоднозначных 10-минутных меток при смене часового пояса Казахстана исключены с учётом в отчёте.
- Рабочее предположение: исходные метки заданы в `Asia/Almaty`; ежедневный запуск происходит в 00:00 этого пояса. Для обучения разрешены цели только до 2026-02-01 00:00 локального времени. Метки внутри кода хранятся в UTC.
- Метеоисточник: [Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api), `models=ecmwf_ifs`, координаты `43.645150,78.535604` и `43.643198,78.538828`. Оба пункта попадают в одну модельную ячейку около `43.620384,78.47891`; различие турбин модель изучает по идентификатору и их мощности.
- Источник не отдаёт точное историческое время публикации в ответе. Мы консервативно допускаем запуск ECMWF не раньше чем через 7 часов после инициализации. Это **явное допущение**, а не доказанный timestamp публикации. Его правило и время выбранного запуска сохраняются с прогнозом.
- Скорость ветра запрашивается в м/с. В прогнозе используются только переменные архивного выпуска: ветер на 10 и 100 м, направление на 100 м, температура на 2 м, давление, календарное время и горизонт. Измеренный в будущем ветер не является входом прогнозной модели.

Сведения об API, доступности запусков и лицензии: [Single Runs](https://open-meteo.com/en/docs/single-runs-api), [условия Open-Meteo](https://open-meteo.com/en/terms). Данные Open-Meteo распространяются по CC BY 4.0 с указанием источника; открытый API предназначен для некоммерческого использования.

## Установка

Нужны Python 3.10+ и [uv](https://docs.astral.sh/uv/). Из корня репозитория:

```bash
uv sync
uv run pytest -q
```

Первое обучение скачивает около 688 ежедневных архивных выпусков и кэширует ответы в `artifacts/weather/`. Если архив временно недоступен, пропущенные даты фиксируются в `training_manifest.json`; фактическая погода их не заменяет. Файлы `raw/`, `artifacts/` и `.venv/` игнорируются Git.

## Обучение и прогноз

```bash
uv run python -m windpower train
uv run python -m windpower forecast --issue 2026-01-31
uv run python -m windpower backtest --from 2026-01-31 --to 2026-02-28
uv run python -m windpower run --issue 2026-02-01
```

`train` строит три семейства кандидатов: монотонную кривую мощности от прогнозного ветра, прямые CatBoost-модели и двухэтапную коррекцию ветра с кривой мощности. Дополнительно проверяется фиксированная смесь 50/50 лучшей прямой модели и двухэтапной. Глубина 4/6, регуляризация 3/10, 500 деревьев и seed 42 заданы заранее. Победитель выбирается по средней MAE на октябре 2025 — январе 2026 при обучении каждого месяца только на прошлом; требуется устойчивое улучшение над базовой кривой. После выбора он переобучается на всей допустимой истории. Февраль не участвует в подборе.

`forecast` сохраняет 48 значений для каждой турбины. `backtest` повторяет 29 запусков с 31 января по 28 февраля включительно и сохраняет каждый выпуск отдельно. `run` проверяет хеш исходных CSV, при изменении переобучает модель и создаёт прогноз. Повтор запуска с теми же моделью и погодным выпуском возвращает тот же файл; новый выпуск получает отдельный `run_id`.

## Качество на проверочных месяцах

На четырёх последовательных месяцах (октябрь 2025 — январь 2026) оценено 11 372 прогнозов «турбина × час × выпуск». Таблица показывает **среднее по месячным метрикам**, поэтому повторяющиеся целевые часы учитываются как отдельные прогнозы разных выпусков.

| Модель | MAE | RMSE |
| --- | ---: | ---: |
| Базовая кривая мощности | 0,18285 | 0,23768 |
| Прямая CatBoost | 0,15955 | 0,23618 |
| Коррекция ветра и кривая мощности | 0,15981 | 0,23141 |
| **Фиксированная смесь 50/50 (выбрана)** | **0,15889** | **0,23299** |

Смесь снизила MAE относительно baseline на **13,1%**. Для выбранной модели MAE по горизонтам 1–24 и 25–48 равен 0,15030 и 0,16777. Декабрь оказался сложнее остальных месяцев (MAE 0,19146); это видно в полном отчёте, а не скрыто усреднением. Значения **не являются метриками февраля**.

## Результаты

| Путь | Содержимое |
| --- | --- |
| `artifacts/model/model.joblib` | Финальная модель и версия. Загружать только из доверенного каталога: формат joblib исполняет Python при десериализации. |
| `artifacts/model/validation_metrics.csv` | MAE, RMSE, смещение и MAE по горизонтам 1–24/25–48 для каждого кандидата и месяца. |
| `artifacts/model/validation_metrics_by_turbine.csv` | Те же метрики по каждой турбине. |
| `artifacts/model/training_manifest.json` | Размеры выборок, качество SCADA, недоступные погодные даты и временные допущения. |
| `artifacts/weather/*.json` | Исходный ответ погодного API, параметры запроса и SHA-256. |
| `artifacts/forecasts/*.csv` | Время выпуска и целевого часа, горизонт, турбина, мощность `[0,1]`, версия модели, хеш погоды и координаты модельной ячейки. |
| `artifacts/runs/*.json` | Статус, шаги, анализ результата и происхождение отдельного прогноза. |
| `artifacts/backtest_*.csv` | Все прогнозы последовательного ретропрогноза. |
| `artifacts/february_latest_forecast.csv` | Один последний допустимый прогноз для каждого часа февраля и каждой турбины: 1 344 строки для передачи на оценку. |

MAE и RMSE выражены в долях нормализованной мощности, а не в МВт·ч. Для расчёта физической выработки нужны паспортные мощности и подтверждённая база нормализации. Ошибки февраля рассчитываются отдельно при появлении фактических февральских значений; их нельзя выдавать за результаты проверки на исторических месяцах.
