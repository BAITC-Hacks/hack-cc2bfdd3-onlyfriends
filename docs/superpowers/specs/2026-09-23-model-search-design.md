# Сравнение моделей и подбор гиперпараметров ВЭС

## Цель

Сравнить 9 семейств почасовых моделей на одних архивных погодных выпусках и одной целевой величине. Найти лучшие параметры внутри заранее заданных сеток, проверить устойчивость против действующей `weather_d6_l10` и обновить рабочую модель только при подтверждённом выигрыше. Февраль 2026 года не имеет доступных фактических меток и не используется для выбора.

## Временной протокол

- Внутренний `GridSearchCV` получает три expanding folds по локальным датам выпуска: июль, август и сентябрь 2025. Для каждого fold обучающие метки имеют `valid_time_utc` строго раньше его начала. Для сентябрьской проверки доступны только метки раньше 1 октября 2025.
- Найденные параметры замораживаются до внешней оценки. Внешние месяцы: октябрь, ноябрь, декабрь 2025 и январь 2026, с переобучением на прошлых метках перед каждым месяцем. Для раннего выпуска 31 января отбор кандидата использует лишь октябрь–декабрь.
- У всех моделей один набор выпусков, часов и турбин. Часы после 31 января 2026 без факта исключаются. Наивная модель может использовать только историю до отсечки; другие модели используют только признаки доступного погодного выпуска.
- Время и происхождение Single Runs остаются ограничены существующим допущением `run + 7h <= issue`; историческая публикация и неизменность hindcast не доказаны.

## Кандидаты

1. Наивная средняя мощность по турбине за окно прошлой истории (30/90/365 дней).
2. Монотонная кривая мощности от прогнозного ветра 10 или 100 м.
3. Ridge с нормировкой и сплайном скорости ветра.
4. ElasticNet с той же линейной схемой признаков.
5. RandomForestRegressor.
6. ExtraTreesRegressor.
7. HistGradientBoostingRegressor.
8. CatBoostRegressor с погодными признаками.
9. MLPRegressor как небольшая нейросеть.

Списки параметров, число деревьев/итераций и random seed фиксируются до расчёта внешних месяцев. Преобразование категориального `turbine_id`, заполнение пропусков и нормировка входят в `Pipeline`, поэтому каждый внутренний fold учит их только на своей обучающей части. Все численные прогнозы ограничиваются `[0,1]` перед расчётом MAE.

## Оценка и выбор

Основная метрика — средняя по четырём внешним месячным MAE; дополнительно RMSE, MAE по каждой турбине и горизонтам 1–24/25–48. Сохраняются лучшие параметры и оценки каждой конфигурации внутреннего поиска, внешние метрики всех девяти моделей и сравнение парных дней выпуска. Стабильный выигрыш требует меньшей MAE против действующей модели как минимум в трёх из четырёх месяцев и меньшей средней MAE. Для первого выпуска — как минимум два выигрыша из трёх месяцев. При отсутствии такого выигрыша текущая модель остаётся рабочей.

Отдельные CatBoost-модели турбин ранее дали среднюю внешнюю MAE 0,15380 против 0,15351 у общей модели и выиграли один из четырёх месяцев. Этот результат сохраняется как контроль конкретной гипотезы; новый поиск также показывает метрики по каждой турбине и не добавляет поправку, если она не проходит временную проверку.

## Артефакты

Отдельный каталог `artifacts/model_search/` содержит таблицы внутреннего поиска, внешней проверки, параметры победителей, парные сравнения и JSON-манифест с временными границами и версиями данных. README показывает каждое семейство и лучшие настройки. Если новая модель проходит правило выбора, она получает новый `algorithm_version`, собственные бинарные версии и заново выпускает 29 прогнозов. Если нет — существующие прогнозы остаются текущими, а результаты поиска публикуются как отрицательный эксперимент.
