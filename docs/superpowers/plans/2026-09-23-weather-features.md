# Погодные признаки и честная проверка — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Согласовать проверку с рабочим прогнозом и проверить новые погодные признаки без использования будущей информации.

**Architecture:** `features.py` строит оба набора из полного отдельного погодного выпуска. `model.py` хранит схему признаков в каждой модели и сравнивает кандидатов на месячных срезах по времени выпуска. `training.py` и `workflow.py` выпускают новые версии, сохраняя старые. Отдельный отчёт сравнивает контрольную и новую модель по месяцам, турбинам, горизонтам и дням выпуска.

**Tech Stack:** Python, pandas, numpy, CatBoost, scikit-learn, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-09-23-weather-features-design.md`

## Global Constraints

- Цель `power` доступна для обучения только до конкретного момента выпуска.
- Проверочный месяц определяется локальной датой `issue_time_utc`; прогноз сохраняет горизонт 1–48.
- Источник погоды — отдельные архивные выпуски `ecmwf_ifs`; доступность оценивается правилом `run <= assumed_available <= issue`.
- Новые признаки используют только полный доступный погодный выпуск, без фактической мощности и ветра из будущего.
- Старые joblib-файлы остаются читаемыми с прежним набором признаков.
- Числа февраля не называются метриками, поскольку фактических меток февраля нет.

## Review Focus

1. Компоненты смеси вне `[0,1]`: оценка и рабочий прогноз должны совпасть — тест задачи 1.
2. Выпуск на границе месяца и его второй день: проверочный срез сохраняет известные целевые часы — тест задачи 1.
3. Отсутствующий соседний час либо тот же час другого выпуска: соседний признак остаётся `NaN` — тест задачи 2.
4. Ранний выпуск 31 января не использует январские данные после него при выборе и обучении — проверка задачи 3.
5. Старый бинарный bundle после расширения признаков делает прежний прогноз, не падая из-за несовпадения колонок — тест задачи 3.
