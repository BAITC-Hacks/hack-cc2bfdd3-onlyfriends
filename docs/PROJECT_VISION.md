# Видение проекта

## Цель

Помочь планировать работу ВЭС: каждый день получать проверяемый почасовой прогноз на 24–48 часов вперёд по историческим данным станции и погодному прогнозу для двух точек. Владельцем кейса указан Самрук-Казына.

## Результат для пользователя

На каждый момент запуска доступны таблица прогнозов по часам, статус расчёта, версии входных данных и модели, краткое объяснение аномалий. При новых допустимых входных данных цикл выполняется повторно. Ошибка загрузки или недостаток данных дают явный статус отказа.

## Границы первой версии

1. Прочитать и проверить историю с марта 2023 года по 31 января 2026 года.
2. Получить для обеих турбин архивные погодные прогнозы с зафиксированным временем инициализации и обоснованной оценкой времени доступности.
3. Обучить модель выработки, используя данные, которые были известны на момент выдачи прогноза.
4. Воспроизвести ежедневные запуски с 31 января по 28 февраля 2026 года; выдавать по 48 почасовых значений на запуск.
5. Сохранить происхождение прогноза и оценить только целевые часы февраля.

Первая версия не требует UI, торгового оптимизатора, управления турбинами, многоагентной системы и перевода нормализованной мощности в энергию без известной базы нормализации.

## Критерии успеха

- Полный сценарий запуска воспроизводим из репозитория и доступных входных файлов.
- Ни один признак или погодный выпуск не появился позже момента соответствующего запуска.
- Есть простой эталон для сравнения и временная проверка качества; метрики указаны честно.
- Результат содержит 48 часов, идентификаторы запуска, модели и погодного выпуска, а также причины отказа.
- Архитектура соответствует реально написанному коду, а автоматизация агента видна в журнале.

Оценка организаторов: соответствие задаче — 25, техника — 25, README и воспроизводимость — 25, ценность — 15, развитие и оригинальность — 10 баллов. Приоритет первой версии: работающий сценарий и доказуемая честность ретропрогноза.

## Открытые решения

Схема данных, часовой пояс, единица целевой величины, момент ежедневного запуска и доступность архивного погодного выпуска должны быть подтверждены до обучения и финальной оценки. Эти решения фиксируются в конфигурации и отчёте о запуске.
