# Источники и действия

## Погодный архив

Кандидат для ретропрогноза — [Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api): он выдаёт отдельный выпуск модели по UTC-времени и сохраняет полный горизонт. По документации архив ECMWF IFS HRES покрывает период с марта 2024 года, включая февраль 2026 года. Условия использования и время публикации выпусков нужно проверить до внедрения.

Пробный запрос для `run=2026-01-31T12:00`, `models=ecmwf_ifs`, `forecast_hours=72`, `wind_speed_100m,temperature_2m` вернул 72 значения каждого показателя для обеих турбин. Обе координаты отобразились в одну ячейку модели `43.620384, 78.47891`, поэтому эти ряды нельзя считать независимыми погодными измерениями. Этот запрос подтверждает лишь один выпуск; полноту архива за весь тестовый период предстоит проверить.

Параметр `run` обозначает время инициализации модели, а не момент публикации. Глобальная модель публикует результат спустя несколько часов. API архива не возвращает исторический `available_at` в проверенном ответе: его нужно обосновать по [расписанию обновлений](https://open-meteo.com/en/docs/model-updates) и консервативной задержке, затем сохранять правило оценки вместе с запуском. Пока правило не подтверждено, нельзя заявлять строгую историческую доступность. Источник: [документация Single Runs](https://open-meteo.com/en/docs/single-runs-api).

[Historical Forecast API](https://open-meteo.com/en/docs/historical-forecast-api) объединяет первые часы последовательных выпусков в непрерывный ряд. Он полезен для исследования и обучения, но сам по себе не воспроизводит единый 48-часовой выпуск на прошлую дату. [Previous Runs API](https://open-meteo.com/en/docs/previous-runs-api) даёт фиксированные интервалы заблаговременности, а не полный конкретный выпуск. Наблюдения и [реанализ](https://open-meteo.com/en/docs/historical-weather-api) не используются как будущая погода в ретропрогнозе.

## Текущие действия агента

`ForecastAgent.run(issue_utc)` в `windpower/agent.py` выполняет один ограниченный граф LangGraph. Инструмент LangChain `fetch_weather_run` принимает UTC-время запуска и вызывает `windpower.weather.fetch_issue` для фиксированных координат двух турбин; адаптер кеширует исходный ответ. Узлы графа проверяют выпуск, строят признаки, вызывают переданный предиктор, валидируют ровно 48 часов на турбину и сохраняют JSON. В случае ошибки агент останавливается до записи прогноза и возвращает код шага. `run_daily` последовательно повторяет граф по дневным UTC-датам с пределом 29 запусков и остановкой при первом отказе.

Второй инструмент LangChain, `search_web`, вызывается только методом `research_sources(query)`. Он использует библиотеку DDGS, возвращает не более пяти HTTPS-ссылок и коротких фрагментов с временем поиска. Этот текущий поиск помогает изучать документы погодных провайдеров; он не выбирает погодный выпуск и не передаёт результаты в прогнозный граф. При ошибке поиска прогнозный цикл не меняется.

## Контракты для развития

| Инструмент | Вход | Выход | Побочный эффект |
| --- | --- | --- | --- |
| `fetch_weather_run` | Координаты, `origin_at`, провайдер/модель | Данные одного выпуска + метаданные | Сетевой запрос, без записи |
| `save_weather_run` | Исходный ответ, модель, время и правило доступности | Идентификатор сохранённого выпуска | Запись неизменяемой копии по идемпотентному ключу |
| `validate_inputs` | История, погодный выпуск, `origin_at` | Список ошибок и статус | Нет |
| `build_features` | Допустимые история и погода, версия схемы | Таблица признаков | Нет |
| `predict_power` | Признаки, версия обученной модели | 48 значений | Нет |
| `validate_forecast` | Значения, часы, целевая схема | Статус и диагностика | Нет |
| `save_forecast` | Проверенный прогноз, ключ запуска | Идентификатор сохранённой версии | Запись по идемпотентному ключу |

Вход и выход текущих действий типизированы. Сетевой адаптер проверяет ответ и единицы, ограничивает время и повторы; координаты берутся из фиксированной конфигурации, а совпадение координат ячейки модели с запросом ещё не проверяется. Чтение погоды создаёт кеш, но не меняет хранилище прогнозов. Неизвестные поля внешнего ответа не превращаются в инструкции агенту.
